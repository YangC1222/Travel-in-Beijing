## 地图与位置说明

- 全程总览显示所有景点；标签引线连接景点真实代表坐标，避免老城区标记重叠。点击标签或编号可查看详情。
- 不同日期使用不同颜色。半透明框是游览片区示意，不是景区或行政边界。
- 虚线仅表示游览顺序，**不是道路导航，也不代表真实距离或所需时间**。
- 坐标使用 WGS84，与 OpenStreetMap 底图保持一致。公园、校园和湖区标记为代表点，非精确入场口。
- 高德入口链接使用地点名称搜索，不把 WGS84 坐标直接传入 GCJ-02 地图。清华入校门按本人入校资格或预约结果选择。
- 底图需要联网；出现加载错误时网页仍保留景点和日程，并提供重试与高德入口链接。无离线瓦片下载或预取功能。

## 本地使用与维护

纯静态 HTML/CSS/JavaScript，无需构建、API Key 或后端。Leaflet 1.9.4 随项目提供，避免脚本 CDN 不可用影响日程。

```sh
python -m http.server 4173
```

打开 `http://localhost:4173`。修改 `data.js` 可调整景点、日期、时间与说明；`transit.js` 存放逐段交通和信息来源；`app.js` 控制交互，`style.css` 控制布局。

GitHub Pages 从 `main` 分支根目录发布。在线地址同时放在仓库 About / Website 中。

## 推荐地铁出口

- 10/1 圆明园：圆明园站 **B 口（东北口）**，走向公园南门。
- 10/2 天坛：天坛东门站 **A2 口（西北口）**。
- 10/3 清华西门：圆明园站 **B 口**；若获准从东南门入校，五道口站 **A 口（北口）**。按实际入校资格选择校门。
- 10/4 雍和宫：雍和宫站 **F 口（东南口）**；当天地坛从五道营步行抵达。若单独坐地铁去地坛南门，可选雍和宫站 **A 口（西北口）**。
- 10/5 南锣鼓巷：南锣鼓巷站 **E 口（西北口）**。
- 10/6 北海：北海北站 **D 口（西南口）**，沿道路南侧向东至北门。

以上为常规开放时的推荐出口，国庆期间如遇封口或单向通行，以站内工作人员与现场导向为准。返程进站不是出站，酒店目的站未知，不虚构酒店附近出口。
